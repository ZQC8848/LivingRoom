# 《人间乐园》环形画厅：素材与合成约定

本目录保存这次已完成的图源、无框裁切、局部生成参考和 8K 全景静帧。没有运行视频生成；提示词和时间参数是待测试的制作起点。

## 清晰度

此前对话原型使用 760 px 左右的压缩整幅图，中联实际上只剩约 380 px 宽。保真度滑块只能关掉额外降采样，不能恢复源图细节。

当前 master 为 8533 × 4325。中联无框裁切为 3990 × 4258。地狱测试取右联上部 1710 × 1928；完整右联另外保存在 `hell-complete-reference.jpg`，避免将上部裁切误称为全幅。

对话内预览因体积限制使用最长边 1536 px 的压缩图。`../bosch-room.html` 内嵌完整裁切，离线可打开。导出 8192 px 只能提供更密的最终采样，不会让源图凭空增加细节。更高的原画扫描参考为 https://commons.wikimedia.org/wiki/File:The_Garden_of_earthly_delights.jpg （39137 × 22279）。

## 投影

眼点固定在圆柱中心。设半画带角 β、纬度 φ，圆柱上的归一化纵坐标为：

`source_v = 0.5 - tan(φ) / (2 × tan(β))`

只有 `abs(φ) < β` 使用画作，边缘以平滑权重融入独立穹顶／地面。顶部和底部不采样原画，所以人物不会被拖到两极。

默认 β = 30°，即画作占赤道上下各 30°。在 8192 × 4096 的 2:1 母版上，画带的纬度高度约为 1365 px，其余为顶部和底部。最终的全景容器仍然覆盖 360° × 180°。

已删除此前的重复和镜像平铺。原作核心只出现一次，水平角跨度按 `2 × tan(β) × 原图宽高比` 计算。默认 β=30° 时，中联覆盖前方约 62°；其余周向明确作为待设计氛围区。这是构图校正版，尚未补成完整的 360° 环境。正式版需以原画核心段为锚，补画／延展新的连续周边，再以相同投影烘焙。

旧版在默认设置下将同一段铺为六段、相邻交替横向镜像。2:1 容器比例当时没有错，错误在于用复制填满空间；当前导出已更新为单次构图。

## 与现有单路视频机制配合

1. 静态层：高清画带 + 穹顶 + 地面。
2. 动态层：只生成需要变化的局部 16:9 裁切。
3. 后期：对齐、稳定、遮罩、短循环；将有效局部投回同一圆柱坐标。
4. 输出：一条 2:1 RGB 全景视频；前端仍使用球面播放器。

## 分区制作与边界

`regions/manifest.json` 保存六个候选区域及其原始坐标。每个区域附有 1024×576 的参考图、活动支持区蒙版起稿和独立提示词。A/B/C 为水面、枝叶和人物候选；D/E/F 为两处火光及烟雾候选。人物候选区还没有完成逐人分割。

所有参考都从同一张高清底图截取，参考上下文可以重叠。生成后先对齐／稳定，再仅把内部活动区回贴；交界与外围缓冲带始终取静态原图。活动支持区之外的合成内容不采纳模型结果，不把两段生成背景直接硬拼。

人物和动作完整范围应放在同一区域，分割线绕开人物。人物位移时要覆盖所有可能位置，必要时先制作干净背景；否则原图中的身体会与新位置重影。任何触及活动边缘、身体截断、越界或身份漂移的片段应重生成／缩小动作，硬裁切本身不能保证人物运动自然。

当前浏览器的人工变化探针验证了合成隔离：在指定活动区内注入变化，区域外像素保持不变。这验证的是合成支持区，不代表真实模型输出已通过动作验收；尚未运行这些生成任务。

Orbis 的模型输入与最终输出格式不相同。公开 schema 规定起始图按 16:9 准备；模型生成 832 × 480，更高交付尺寸属于放大。不要让低分辨率生成层替换整张高清底图。视点、运动范围和区域外不变应由合成保证，不能只依赖文字提示。

如果手势揭示需要即时变化，可以在本地合成两层状态后再形成一路全景；现有视频中继若只转发而不做合成，需要补上这一处理。当前新原型直接验证同一套 GPU 合成着色器，并输出静帧参考，尚未接入视频中继。

## 微动与循环

初始建议：只做 1–3 处，总变化区域约占画带 5% 以内。火光先取 2–4 秒稳定素材，单个人物先取 4–6 秒完成一次动作。时长不是 API 的硬承诺，需按实际输出帧截取、验收。

“稍微动一下”不是充分约束。每项应指定人物／物体、变化部位、位移范围、终止姿态与静止部分。优先使用偏头、手腕、呼吸、火光；行走会不断改变位置、遮挡和人物关系。

生成漂移和播放卡顿是两个问题：短段有利于控制漂移，但解码、码率、预加载、首帧和 GPU 合成负载仍需在实际头显上测量。当前浏览器验收不能代替头显验收。
