针对《人间乐园》的新版素材与投影研究为 `bosch-room.html`：采用 8533 px 图源的无框裁切，原作核心只出现一次，圆柱画带、独立顶底、柔和边缘和 2:1 排版切换。已经删除镜像／重复平铺，其余周向明确作为待设计氛围区。完整裁切内嵌在该单文件里；对话预览另外压缩。`bosch-hd/` 含更新后的 8K 单次构图静帧、六处局部 16:9 生成参考与支持蒙版、提示词和 `integration.json`；详细说明见 `bosch-hd/PIPELINE.md`。新研究直接用 GPU 验证合成，尚未连视频中继或生成模型。

这版花园／地狱以原画分联裁切、镜像延展构成连续全景草图，存在重复意象；它不是最终的全景美术，也不是历史复原。火焰是程序占位，并非模型实测结果。正式制作需重新设计固定视点的全景构图、对应地标与遮罩，再将经过处理的视频片段接入动态层。其他作品沿用上一轮低保真互动，尚未全部改成完整的画中空间。

包含十个新方向，以及原先四个方向的固定视点改编。左侧切换实验，拖动画面转头，点击圆点或操作按钮代替手势。窄屏使用顶部下拉选择。画面保真度用于比较原画参照、低保真和像素状态。每项可标记审阅意见；在 Codex 内通过会话状态保存，独立浏览器版只保留本次页面内状态。

## 本次验证什么

- 一个局部变化是否能让观众重新理解画中关系。
- 选择、删改、观看与修复能否产生可理解的后果。
- 在固定位置、只允许转头的条件下，证据与后果怎样分布在周围。
- 降低画面保真度后，哪些线索仍能被辨认。

本原型使用预制状态、局部图像采样和程序合成。没有调用 Orbis、ComfyUI、眼动或头显手势。图像延展、遮去人物、目光线、替换字幕和修复情境都属于当代设计演绎；界面中的“依据与改编”逐项区分史料与演绎。

## 单路画面流程

原画 + 局部状态 / 遮罩 → 一张 2048 × 1024 全景画布 → `captureStream(12)` 的单条视频轨 → 球面方向采样。

浏览器不支持画布视频流时，直接使用同一张全景画布作为回退。观众位置始终不变；鼠标拖动只改变朝向。球面背景与画作周围的留白是空间草图，并非真实展厅或画中建筑复原。

接入实际内容制作时，可以用 ComfyUI 等工具先处理人物分割、背景补全、指定区域的状态或短动作，再把结果对齐到原画。最终合成仍输出一路全景视频；无需要求生成模型直接输出完整透明图层。此版没有提供或验证具体 ComfyUI 节点工作流。

## 文件

- `prototype.fragment.html`：可维护的界面与合成程序。
- `studies.js`：14 项互动、研究依据与改编声明。
- `assets/`、`sources.json`：公共领域画作素材与来源页面。
- `fetch_assets.py`：下载并压缩素材；联网执行。
- `build.py`：生成独立浏览器页面和对话内预览片段。
- `verify.cjs`：使用本机 Chrome 检查实际点击、视频轨、全景转头及窄屏布局。
- `review/verification.json`、`review/*.png`：检查记录与截图。

素材使用 Wikimedia Commons 的公共领域作品复刻图；每个具体文件的来源页记录在 `sources.json`。埃舍尔方向使用原创几何草图，不使用其作品图像。
